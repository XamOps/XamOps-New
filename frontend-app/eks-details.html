Complete Monitoring Setup Guide

This guide will help you set up a complete monitoring solution that collects:

  • System Metrics: CPU, memory, disk, network from nodes
  • Kubernetes Metrics: Pods, deployments, nodes, services
  • Security Events: Runtime security alerts via Falco
  • Cost Metrics: AWS EC2 instance costs per node

Metric Naming Convention

The XamOps application expects specific metric naming patterns:

Data Type Metric Prefix Example
OTel/System Metrics xamops_eks_ xamops_eks_k8s_node_cpu_usage
Kube-State Metrics xamops_eks_ xamops_eks_kube_pod_info
Cost Metrics xamops_eks_xamops_eks_ xamops_eks_xamops_eks_cluster_total_daily_cost
Falco Security xamops_eks_falcosecurity_... xamops_eks_falcosecurity_falcosidekick_falco_events_total

Note: Cost metrics have a double prefix (xamops_eks_xamops_eks_) by design because the cost-exporter exports with xamops_eks_ prefix, and OTel adds another xamops_eks_ prefix during collection.

Prerequisites

AWS Requirements

  • AWS Account with EKS cluster access
  • IAM permissions to create roles and policies
  • VPC with proper networking (private/public subnets)
  • EC2 instance for monitoring stack (t3.medium or larger, 20GB+ storage)

Tools Required

  • kubectl (v1.28+)
  • helm (v3.12+)
  • aws-cli (v2.x)
  • docker and docker-compose
  • SSH access to EC2 instances

Network Requirements

Security Group for monitoring instance must allow:

Port 4317 (gRPC) - Inbound from EKS cluster CIDR
Port 4318 (HTTP) - Inbound from EKS cluster CIDR
Port 9090 (Prometheus UI) - Inbound from your IP/application
Port 22 (SSH) - Inbound from your IP

Prerequisite: Launch an EC2 instance with: AMI: Amazon Linux 2023 or Ubuntu 22.04 | Instance Type: t3.medium (2 vCPU, 4GB RAM minimum) | Storage: 20GB GP3 | VPC: Same VPC as EKS cluster

# SSH into the monitoring instance
ssh -i your-key.pem ec2-user@<MONITORING_INSTANCE_IP>

Create Prometheus Configuration

Create the Prometheus configuration file that defines how Prometheus scrapes metrics and stores data:

# Create Prometheus configuration file
cat > ~/monitoring/prometheus.yml << 'EOF'
# Prometheus Configuration
# This file defines how Prometheus scrapes metrics and stores data

global:
  # How often to scrape targets by default
  scrape_interval: 15s

  # How often to evaluate alerting rules
  evaluation_interval: 15s

# Remote write allows Prometheus to accept metrics from remote sources
remote_write:
  - url: http://localhost:9090/api/v1/write

# Scrape configurations define what endpoints Prometheus will scrape
scrape_configs:
  # Job 1: Scrape the OTel Gateway's Prometheus exporter endpoint
  # The OTel Gateway exposes metrics about itself and forwards cluster metrics
  - job_name: 'otel-gateway'
    static_configs:
      - targets: ['otel-gateway:8889']  # OTel Gateway's metrics endpoint
    scrape_interval: 30s  # Scrape every 30 seconds

  # Job 2: Scrape Prometheus itself for self-monitoring
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']  # Prometheus self-monitoring
EOF

        endpoint: "0.0.0.0:4317"
      http:
        endpoint: "0.0.0.0:4318"

  prometheusremotewrite:
    endpoint: "http://prometheus:9090/api/v1/write"
    namespace: xamops_eks
    tls:
      insecure: true

  prometheus:
    endpoint: "0.0.0.0:8889"
    namespace: xamops_eks

processors:
  batch:
    timeout: 10s
    send_batch_size: 1024

  resource:
    attributes:
      - key: cluster_name

        action: insert

  attributes:
    actions:
      - key: cluster_name
        value: <YOUR_CLUSTER_NAME>  # CHANGE THIS to your cluster name
        action: insert

service:
  pipelines:
    metrics:
      receivers: [otlp]
      processors: [batch, resource, attributes]
      exporters: [prometheusremotewrite, prometheus]
EOF

Create IAM Role for Cost Exporter

IMPORTANT: Replace <YOUR_CLUSTER_NAME> and <YOUR_REGION>

cat > create-cost-exporter-role.sh << 'SCRIPT'
#!/bin/bash
CLUSTER_NAME="<YOUR_CLUSTER_NAME>"
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
REGION="<YOUR_REGION>"

OIDC_PROVIDER=$(aws eks describe-cluster --name $CLUSTER_NAME --region $REGION \
  --query "cluster.identity.oidc.issuer" --output text | sed -e "s/^https:\/\///")

cat > /tmp/trust-policy.json << TRUST
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": {"Federated": "arn:aws:iam::${ACCOUNT_ID}:oidc-provider/${OIDC_PROVIDER}"},
    "Action": "sts:AssumeRoleWithWebIdentity",
    "Condition": {
      "StringEquals": {
        "${OIDC_PROVIDER}:sub": "system:serviceaccount:default:cost-exporter",
        "${OIDC_PROVIDER}:aud": "sts.amazonaws.com"
      }
    }
  }]
}
TRUST

cat > /tmp/cost-exporter-policy.json << POLICY
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["ec2:DescribeInstances", "ec2:DescribeTags", "ce:GetCostAndUsage"],
    "Resource": "*"
  }]
}
POLICY

aws iam create-role --role-name ${CLUSTER_NAME}-CostExporterRole --assume-role-policy-document file:///tmp/trust-policy.json
aws iam put-role-policy --role-name ${CLUSTER_NAME}-CostExporterRole --policy-name CostExporterPolicy --policy-document file:///tmp/cost-exporter-policy.json

echo "Role ARN: arn:aws:iam::${ACCOUNT_ID}:role/${CLUSTER_NAME}-CostExporterRole"
SCRIPT

chmod +x create-cost-exporter-role.sh
./create-cost-exporter-role.sh

        't3.large': 0.0832, 't3.xlarge': 0.1664, 't3.2xlarge': 0.3328,
        't2.small': 0.023, 't2.medium': 0.046, 't2.large': 0.093,
        'm5.large': 0.096, 'm5.xlarge': 0.192, 'm5.2xlarge': 0.384,
        'm6i.large': 0.096, 'm6i.xlarge': 0.192, 'c5.large': 0.085,
        'c5.xlarge': 0.17, 'c6i.large': 0.085, 'c6i.xlarge': 0.17,
    }

    def get_instance_cost(instance_type):
        return INSTANCE_PRICING.get(instance_type, 0.10)

    def get_cluster_nodes():
        ec2 = boto3.client('ec2', region_name=REGION)
        response = ec2.describe_instances(
            Filters=[
                {'Name': 'tag:eks:cluster-name', 'Values': [CLUSTER_NAME]},
                {'Name': 'instance-state-name', 'Values': ['running']}
            ]
        )
        nodes = []
        for reservation in response['Reservations']:
            for instance in reservation['Instances']:
                node_name = instance['PrivateDnsName']
                for tag in instance.get('Tags', []):
                    if tag['Key'] == 'Name':
                        node_name = tag['Value']
                        break
                nodes.append({
                    'node_name': node_name,
                    'instance_id': instance['InstanceId'],
                    'instance_type': instance['InstanceType']
                })
        return nodes

    def update_metrics():
        try:
            nodes = get_cluster_nodes()
            total_daily_cost = 0
            for node in nodes:
                cost_per_hour = get_instance_cost(node['instance_type'])
                daily_cost = cost_per_hour * 24
                NODE_COST_GAUGE.labels(
                    cluster_name=CLUSTER_NAME, node_name=node['node_name'],
                    instance_type=node['instance_type'], instance_id=node['instance_id']
                ).set(cost_per_hour)
                NODE_DAILY_COST_GAUGE.labels(
                    cluster_name=CLUSTER_NAME, node_name=node['node_name'],
                    instance_type=node['instance_type'], instance_id=node['instance_id']
                ).set(daily_cost)
                total_daily_cost += daily_cost
            CLUSTER_TOTAL_COST_GAUGE.labels(cluster_name=CLUSTER_NAME).set(total_daily_cost)
            print(f"Updated metrics for {len(nodes)} nodes. Total daily cost: ${total_daily_cost:.2f}")
        except Exception as e:
            print(f"Error updating metrics: {e}")

    if __name__ == '__main__':
        start_http_server(8080)
        print("Cost exporter started on port 8080")
        while True:
            update_metrics()
            time.sleep(300)
EOF
