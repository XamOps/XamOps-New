Cluster Integration Guide

Setup monitoring, security & compliance tools

Unlock Full Observability

To unlock the full potential of XamOps—including real-time cost analysis, security vulnerability scanning, and compliance auditing—you must configure your infrastructure to expose the necessary data.

1

Setup Metrics Gateway (EC2 Instance)

Prerequisite: Ubuntu t3.medium EC2 • Open Ports 9090 & 4318

SSH into your EC2 instance and run the following commands:

# Install Docker
sudo apt-get update && sudo apt-get install -y docker.io docker-compose

# Create directory structure
mkdir -p ~/xamops-gateway/config && cd ~/xamops-gateway

# Create Prometheus Configuration
cat <<'EOFPROM' > config/prometheus.yaml
global:
  scrape_interval: 15s
scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
EOFPROM

# Create Docker Compose
cat <<'EOFDOCKER' > docker-compose.yaml
version: '3'
services:
  prometheus:
    image: prom/prometheus:latest
    volumes:
      - ./config/prometheus.yaml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"
  otel-gateway:
    image: otel/opentelemetry-collector-contrib:latest
    command: ["--config=/etc/otel-collector-config.yaml"]
    volumes:
      - ./config/otel-gateway.yaml:/etc/otel-collector-config.yaml
    ports:
      - "4318:4318"
EOFDOCKER

# Start Services
sudo docker-compose up -d
2

Install Cluster Monitoring Agents

# Install Kube State Metrics
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm install kube-state-metrics prometheus-community/kube-state-metrics --namespace kube-system

# Install Falco (Security)
helm repo add falcosecurity https://falcosecurity.github.io/charts
helm install falco falcosecurity/falco --namespace falco --create-namespace \
  --set falcosidekick.enabled=true --set falcosidekick.config.prometheus.enabled=true
3

Install Compliance & Vulnerability Scanners

Kubescape 

helm repo add kubescape https://kubescape.github.io/helm-charts/
helm install kubescape kubescape/kubescape-operator \
  --namespace kubescape --create-namespace \
  --set clusterName=YOUR_CLUSTER

Trivy

helm repo add aqua https://aquasecurity.github.io/helm-charts/
helm install trivy-operator aqua/trivy-operator \
  --namespace trivy-system --create-namespace
4

Generate Kubeconfig for XamOps

Create a restricted service account for XamOps to read security scan results:

# Create Service Account
kubectl apply -f - <<'EOFSA'
apiVersion: v1
kind: ServiceAccount
metadata: { name: xamops-reader, namespace: default }
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata: { name: xamops-reader-role }
rules:
- apiGroups: ["aquasecurity.github.io", "spdx.softwarecomposition.kubescape.io"]
  resources: ["vulnerabilityreports", "configurationscansummaries"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata: { name: xamops-reader-binding }
subjects:
- kind: ServiceAccount
  name: xamops-reader
  namespace: default
roleRef:
  kind: ClusterRole
  name: xamops-reader-role
EOFSA

# Generate kubeconfig (save output to file)
kubectl create token xamops-reader --duration=87600h

Next Steps

  • Save your EC2 public IP (e.g., http://1.2.3.4:9090) for Prometheus queries
  • Wait 5-10 minutes for initial security scans to complete
  • Provide the kubeconfig token to XamOps for integration
