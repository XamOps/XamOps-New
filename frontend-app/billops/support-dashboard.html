Microsoft Teams Setup

  1. Teams uses per-user Incoming Webhook URLs — no global token needed
  2. In the user's Teams channel: Apps → Incoming Webhooks → Add → copy the URL
  3. Paste that webhook URL in the user's connection settings (in the chat panel below)
  4. For inbound replies: create an Outgoing Webhook pointing to
Teams is configured per-user via Webhook URLs. Use the "Connect Platform" button in the chat header.

Google Chat Setup

  1. Google Chat uses per-user Space Webhook URLs — no global token needed
  2. In the user's Google Chat space: Apps & Integrations → Webhooks → Add → copy the URL
  3. Paste that webhook URL in the user's connection settings (in the chat panel below)
  4. For inbound replies: configure Google Chat App URL to
Google Chat is configured per-user via Webhook URLs. Use the "Connect Platform" button in the chat header.
