## 2026-07-17 - Onboarding Form Accessibility Standard using React 19's useId Hook
**Learning:** Onboarding modals and dynamic registration flows in this application frequently lack semantic linking between descriptive `<label>` elements and their respective form controls (such as `<input>` and `<textarea>`). Hardcoding string IDs on inputs in a single-page application risks duplicate ID collisions when modals mount/unmount or render dynamically. React 19's native `useId` hook provides a robust, stable mechanism to link labels (`htmlFor`) to inputs (`id`) without manual collision tracking. Additionally, lists of dynamic fields (like multi-cloud Account IDs) must use runtime index-based `aria-label` attributes to ensure screen readers can announce contextually unique actions for adding or removing list items.
**Action:** Always wrap onboarding and configuration form fields with `useId` to associate labels to inputs. Standardize dynamic loop inputs/buttons with template-literal index labels (e.g., `aria-label={\`Remove Cloud Account ID \${idx + 1}\`}`) to ensure high accessibility scores.
