## 2025-05-15 - Accessible SuperAdminTopBar
**Learning:** Linking `<label>` to `<select>` via `useId` and wrapping icon-only buttons in `TooltipWrapper` with explicit `aria-label` and focus rings is a repeatable pattern for high-quality, accessible UI components in this project.
**Action:** Always check for unlinked labels and missing ARIA labels on icon buttons in existing components.
