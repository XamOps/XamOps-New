## 2026-07-17 - Mobile Menu State Accessibility Tracking
**Learning:** In responsive and mobile interfaces, screen readers rely heavily on aria-expanded attributes to announce whether collapsible navigation drawers are open or collapsed. Interactive hamburger controls must always link their state dynamically to the screen reader so visually impaired users can navigate menus correctly.
**Action:** Always bind aria-expanded dynamic state on collapsible layout buttons such as hamburger menu buttons.
