## 2026-06-09 - [CRITICAL] CloudShell IDOR and Cross-Tenant Unauthorized Access
**Vulnerability:** The `/terminal` WebSocket endpoint allowed unauthenticated access and relied on client-side query parameters (`accountId`, `tenantId`) to establish shell sessions. This enabled IDOR (Insecure Direct Object Reference) and cross-tenant data access, allowing any user (or unauthenticated attacker) to open a shell for any cloud account in the system.
**Learning:** WebSocket handlers often bypass standard Spring Security path protections if not explicitly configured or if the handler doesn't manually verify the `Principal`. Blindly trusting query parameters for tenant/resource identification is a major security risk.
**Prevention:** Always enforce mandatory authentication in WebSocket handlers by checking `session.getPrincipal()`. Resolve tenant and resource ownership using the authenticated user's details (e.g., `ClientUserDetails`) rather than raw request inputs. Remove sensitive endpoints from `permitAll()` whitelists.
