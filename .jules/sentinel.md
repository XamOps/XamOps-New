## 2026-07-17 - Securing AgentController UI-Facing Endpoints
**Vulnerability:** UI-facing endpoints in `AgentController.java` (including `/install-info` leaking the global agent API key, and `/db/config` leaking sensitive database credentials) lacked any `@PreAuthorize("isAuthenticated()")` checks. Because of Spring Security's wildcard `permitAll()` configuration for `/api/v1/agent/**`, these endpoints were completely exposed to unauthenticated public access.
**Learning:** Overly broad wildcard patterns like `/api/v1/agent/**` in Spring Security configs can inadvertently expose sensitive management endpoints when developer awareness of class-level controllers is decoupled from centralized configuration.
**Prevention:** Always enforce explicit, narrow session or token authentication boundaries at the controller/method level via `@PreAuthorize("isAuthenticated()")` for UI-facing endpoints, and ensure unit/integration tests explicitly verify security annotations are present.
