## 2026-07-25 - [Predictable OTP & User Enumeration Hardening]
**Vulnerability:** Weak PRNG `java.util.Random` was used to generate 6-digit OTPs in `PasswordResetController` and `LoginOtpController` (CWE-330). Additionally, `PasswordResetController` was susceptible to user enumeration by returning a 400 bad request with "No account found..." when a non-existent email requested a reset, and exposed raw exception messages (CWE-209).
**Learning:** Legacy codebase patterns often utilize standard `java.util.Random` for simplicity, overlooking PRNG predictability. User-facing flow error messages can easily leak the existence of user accounts and internal exception details if not strictly audited.
**Prevention:** Always use `java.security.SecureRandom` for security-sensitive tokens/codes. Mask user existence check outcomes in password reset/forgot-password endpoints with a generic response ("If that email address is registered..."), and sanitize all unhandled exception responses globally.
