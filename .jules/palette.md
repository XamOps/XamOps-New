## 2025-05-15 - Consistent Keyboard Focus States
**Learning:** Standardizing focus states using Tailwind's `focus-visible` classes improves accessibility and provides a cohesive feel for keyboard users. Relying on global CSS can sometimes be shadowed by Tailwind's resets or specific component styles.
**Action:** Use `outline-none focus-visible:ring-2 focus-visible:ring-indigo-500 focus-visible:ring-offset-1` for primary interactive elements in the frontend-app.
