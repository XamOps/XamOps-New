# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Consolidate Design Patterns
**Learning:** Even micro-UX improvements must strictly adhere to the project's established design system and library choices (e.g., using `react-icons` instead of FontAwesome) to avoid visual regressions and build failures.
**Action:** Always verify the project's dependency list and existing component patterns before introducing new UI elements or styles.
